# Seed Data Dictionary

This folder contains JSON files used to seed BigQuery and Firestore with sample data for the EduPulse platform.

```
data/
├── bigquery/                    # Historical analytics data
│   ├── students.json
│   ├── risk_scores.json
│   ├── enrollments.json
│   ├── department_comparison.json
│   └── retention_trends.json
├── firestore/                   # Real-time operational data
│   ├── engagement.json
│   ├── alerts.json
│   ├── notes.json
│   └── sessions.json
├── schemas/                     # Table schemas and knowledge base
│   ├── students.json            # BigQuery schema definition
│   ├── sample/
│   │   └── students.csv         # Sample CSV matching schema
│   └── documents/               # Knowledge base documents for Gemini Enterprise Agent Platform Search
│       ├── student/
│       │   └── sample_student_info.txt   # Registration, policies, resources
│       ├── course/
│       │   └── sample_course_catalog.txt # CS course catalog
│       └── financial/
│           └── sample_financial_aid.txt  # Financial aid guide
└── README.md                    # This file
```

## BigQuery Data (default dataset: `edupulse_student_data`, configurable via `BIGQUERY_DATASET_STUDENT`)

### students.json
**Purpose**: Core student records for the institution.

| Field | Type | Description |
|-------|------|-------------|
| `student_id` | string | Unique identifier (e.g., `STU001`) |
| `name` | string | Full name |
| `email` | string | University email |
| `major` | string | Declared major |
| `year` | string | Academic year (Freshman/Sophomore/Junior/Senior) |
| `gpa` | float | Current GPA (0.0 - 4.0) |
| `credits_completed` | int | Credits earned |
| `credits_attempted` | int | Credits enrolled |
| `enrollment_status` | string | active/withdrawn/graduated |
| `advisor_id` | string | Assigned advisor reference |

### risk_scores.json
**Purpose**: Risk assessments generated by the risk_predictor_agent.

| Field | Type | Description |
|-------|------|-------------|
| `risk_id` | string | Unique identifier (e.g., `RISK001`) |
| `student_id` | string | Reference to students table |
| `risk_score` | int | Risk score 0-100 (higher = more risk) |
| `risk_level` | string | low/medium/high/critical |
| `contributing_factors` | string | Pipe-separated list of risk factors |
| `recommendations` | string | Pipe-separated list of interventions |

### enrollments.json
**Purpose**: Student-course enrollment records.

| Field | Type | Description |
|-------|------|-------------|
| `enrollment_id` | string | Unique identifier (e.g., `ENR001`) |
| `student_id` | string | Reference to students table |
| `course_id` | string | Course code (e.g., `CS101`) |
| `semester` | string | Semester (e.g., `Spring 2026`) |
| `grade` | string | Final grade (A/B+/B/C+/C/D/F) |
| `status` | string | completed/in-progress/withdrawn |
| `attendance_rate` | float | Attendance percentage (0.0 - 1.0) |

## BigQuery Data (default dataset: `edupulse_analytics`, configurable via `BIGQUERY_DATASET_ANALYTICS`)

### department_comparison.json
**Purpose**: Cross-department performance metrics for admin analytics.

| Field | Type | Description |
|-------|------|-------------|
| `department` | string | Department name |
| `avg_gpa` | float | Average GPA across department |
| `retention_rate` | float | Student retention rate (0.0 - 1.0) |
| `graduation_rate` | float | Graduation rate (0.0 - 1.0) |
| `dropout_rate` | float | Dropout rate (0.0 - 1.0) |
| `at_risk_count` | int | Number of at-risk students |
| `total_students` | int | Total enrolled students |

### retention_trends.json
**Purpose**: Semester retention trends by department for historical analysis.

| Field | Type | Description |
|-------|------|-------------|
| `semester` | string | Semester (e.g., `2026-01`) |
| `retention_rate` | float | Retention rate for the semester |
| `enrolled_count` | int | Students enrolled |
| `withdrawn_count` | int | Students who withdrew |
| `department` | string | Department name or `All` for institution-wide |

## Firestore Data (Real-time)

### engagement.json
**Purpose**: Live LMS activity and student engagement data.

| Field | Type | Description |
|-------|------|-------------|
| `student_id` | string | Reference to student |
| `timestamp` | string | ISO 8601 timestamp |
| `activity_type` | string | lms_login/assignment_submission/tutoring_session/office_hours |
| `source` | string | lms/tutoring/advising |
| `session_duration_minutes` | int | Duration of activity |
| `pages_viewed` | int | Pages accessed (LMS only) |
| `resources_accessed` | int | Resources downloaded (LMS only) |
| `submission_status` | string | on_time/late (assignments) |
| `submission_quality` | string | excellent/good/poor (assignments) |
| `subject` | string | Subject area (tutoring) |
| `helpful` | bool | Was session helpful (tutoring) |
| `topic` | string | Discussion topic (office hours) |
| `duration_minutes` | int | Session duration (tutoring/office hours) |

### alerts.json
**Purpose**: Active alerts for at-risk students.

| Field | Type | Description |
|-------|------|-------------|
| `alert_id` | string | Unique identifier (e.g., `ALT001`) |
| `student_id` | string | Reference to student |
| `alert_type` | string | risk/academic/behavior/financial |
| `severity` | string | low/medium/high/critical |
| `title` | string | Alert title |
| `description` | string | Detailed description |
| `created_at` | string | ISO 8601 timestamp |
| `status` | string | active/acknowledged/resolved |

### notes.json
**Purpose**: Advisor-student interaction notes.

| Field | Type | Description |
|-------|------|-------------|
| `note_id` | string | Unique identifier (e.g., `NT001`) |
| `student_id` | string | Reference to student |
| `advisor_id` | string | Reference to advisor |
| `timestamp` | string | ISO 8601 timestamp |
| `category` | string | academic/financial/personal/wellness |
| `note` | string | Detailed note content |
| `follow_up_date` | string | Date for follow-up (YYYY-MM-DD) |
| `follow_up_completed` | bool | Whether follow-up was completed |

### sessions.json
**Purpose**: AI agent session history.

| Field | Type | Description |
|-------|------|-------------|
| `session_id` | string | Unique identifier (e.g., `SES001`) |
| `student_id` | string | Reference to student |
| `agent` | string | Agent that handled session |
| `timestamp` | string | ISO 8601 timestamp |
| `user_message` | string | Student's message |
| `agent_response` | string | Agent's response |
| `intent_detected` | string | Classified intent |

## BigQuery Schema (schemas/students.json)

Defines the BigQuery table schema for the `students` table:

| Field | Type | Mode | Description |
|-------|------|------|-------------|
| `student_id` | STRING | REQUIRED | Unique student identifier |
| `first_name` | STRING | NULLABLE | Student first name |
| `last_name` | STRING | NULLABLE | Student last name |
| `email` | STRING | NULLABLE | Student email address |
| `enrollment_date` | DATE | NULLABLE | Date of enrollment |
| `current_gpa` | FLOAT64 | NULLABLE | Current cumulative GPA |
| `gpa_trend` | STRING | NULLABLE | GPA trend (improving, stable, declining) |
| `attendance_rate` | FLOAT64 | NULLABLE | Class attendance rate (0-1) |
| `enrollment_status` | STRING | NULLABLE | Current enrollment status (active, leave, withdrawn) |
| `credit_hours_completed` | INTEGER | NULLABLE | Total credit hours completed |
| `credit_hours_attempted` | INTEGER | NULLABLE | Total credit hours attempted |
| `risk_score` | INTEGER | NULLABLE | AI-generated risk score (0-100) |
| `risk_level` | STRING | NULLABLE | Risk level (low, medium, high, critical) |
| `last_risk_assessment` | TIMESTAMP | NULLABLE | Timestamp of last risk assessment |
| `advisor_id` | STRING | NULLABLE | Assigned advisor ID |
| `department` | STRING | NULLABLE | Academic department |
| `major` | STRING | NULLABLE | Declared major |
| `classification` | STRING | NULLABLE | Student classification (freshman, sophomore, junior, senior) |
| `is_first_generation` | BOOLEAN | NULLABLE | First-generation college student |
| `is_transfer_student` | BOOLEAN | NULLABLE | Transfer student status |
| `housing_status` | STRING | NULLABLE | Housing status (on-campus, off-campus, commuter) |
| `financial_aid_status` | STRING | NULLABLE | Financial aid status (full, partial, none, pending) |
| `created_at` | TIMESTAMP | NULLABLE | Record creation timestamp |
| `updated_at` | TIMESTAMP | NULLABLE | Record last updated timestamp |
